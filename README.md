# Smarter Angular mit Prompt API & WebMCP

[JavaScript & Angular Days Berlin 2026](https://javascript-days.de/angular/smarter-angular-mit-transformersjs-prompt-api/), 14. Oktober 2026, 14:00–17:30 Uhr

Trainer: Christian Liebel ([@christianliebel](https://x.com/christianliebel))

---

In diesem praxisorientierten Workshop lernst du, wie du deine Angular-basierten Apps mit neuen Web-APIs für generative KI wie der Prompt API smarter machst und mithilfe von WebMCP mit KI-Agenten integrierst.

Wir integrieren einen kontextsensitiven Chatbot per Prompt API in eine Todo-App und extrahieren Daten aus unstrukturierten Eingaben, um sie in ein strukturiertes Formular zu überführen. Hierzu kommt Structured Output der Prompt API zum Einsatz. Über WebMCP öffnen wir die App außerdem für externe KI-Agenten, sodass sie auch von außen gesteuert werden kann.

Abschließend bewerten wir die gezeigten Technologien und geben einen Ausblick auf Browserunterstützung und Standardisierung. Und du entwickelst aktiv mit, wenn du willst.

1. Vorstellung der Demo Use Cases
1. Übersicht und Verwendung der Prompt API
1. Grundlagen zu agentischem Browsen
1. Übersicht und Verwendung von WebMCP
1. Bewertung und Ausblick

## Installationsanweisungen

Wenn Sie mitentwickeln möchten, bringen Sie bitte ein leistungsfähiges Gerät mit Windows oder macOS, eine aktuelle Version von Chrome, Node.js, einen Editor Ihrer Wahl und mindestens 20 GB freien Festplattenspeicher mit.

Idealerweise ist dies Ihr privates Gerät, da Gruppenrichtlinien oder Unternehmensproxys oft Probleme verursachen.

Nachdem Sie das Repository geklont haben, führen Sie bitte die folgenden Befehle in der Kommandozeile aus:

```sh
cd angular-days-2026-fall-prompt-api
npm i
```
